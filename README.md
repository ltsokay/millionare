# Кто хочет стать миллионером? — Java

Настольное приложение по мотивам телешоу. Реализованы все пункты задания,
включая хранение данных в SQLite, таблицу рекордов TOP-10, генерацию вопросов
через ИИ и все пять подсказок.

---

## 1. Что реализовано (по критериям оценивания)

| Пункт задания | Где реализовано | Баллы |
|---|---|---|
| Базовая игра: 15 вопросов нарастающей сложности, призовая лестница, несгораемая сумма | `GameFrame.java`, `Prizes.java` | базовый |
| **Хранение вопросов в БД SQLite** | `Database.java` (таблица `Questions`, автоимпорт из `Вопросы.txt`) | **6** |
| **Таблица рекордов + вывод TOP-10** | `Database.java` (таблица `Records`), `RecordsDialog.java` | **8** |
| **Динамическая генерация вопросов через генеративный ИИ (API)** | `AIQuestionGenerator.java`, `Json.java` | **9–10** |
| Остальные подсказки (помимо «50/50») | `GameFrame.java`, `AudienceDialog.java`, `FriendCallDialog.java` | — |

Подсказки (по правилам можно использовать **любые 4 из 5**):
1. **50 : 50** — убираются два неверных варианта.
2. **Помощь зала** — зрители голосуют, показывается столбчатая диаграмма.
3. **Звонок другу** — друг советует вариант, идёт 30-секундный отсчёт.
4. **Право на ошибку** — на текущий вопрос можно дать два ответа.
5. **Замена вопроса** — текущий вопрос заменяется другим того же уровня.

## 2. Требования

- **JDK 11 или новее** (рекомендуется 17 или 21). Используются `java.net.http`,
  `Path.of`, `String.isBlank()`.
- **Драйвер SQLite** `sqlite-jdbc-*.jar`. Скачать со страницы релизов:
  https://github.com/xerial/sqlite-jdbc/releases — и положить в папку `lib/`.
- Рядом с приложением должны лежать `Вопросы.txt` и `picture.jpg`
  (они уже в корне проекта).

## 3. Запуск

### Вариант А. Командная строка (быстро)

Windows:
```
run.bat
```
Linux/macOS:
```
chmod +x run.sh
./run.sh
```
Скрипт компилирует `src/millionaire/*.java` в папку `out/` и запускает игру.

### Вариант Б. NetBeans / IntelliJ IDEA

1. Создайте Java-проект (без главного класса).
2. Скопируйте пакет `millionaire` (папку `src/millionaire`) в исходники проекта.
3. Подключите библиотеку `lib/sqlite-jdbc-*.jar`:
   - NetBeans: ПКМ по проекту → *Свойства* → *Библиотеки* → *Add JAR/Folder*;
   - IntelliJ IDEA: *File → Project Structure → Libraries → +*.
4. Положите `Вопросы.txt`, `picture.jpg`, `ai_config.properties` в **корневую
   папку проекта** (рабочий каталог при запуске).
5. Запустите класс `millionaire.Main`.

> Интерфейс собирается программно (без `.form`-файла), поэтому редактор форм
> NetBeans не требуется — достаточно добавить классы как обычные `.java`-файлы.

## 4. База данных

Файл `WhoWantsToBeAMillionaire.db` создаётся **автоматически** при первом запуске:

- таблица `Questions` наполняется из `Вопросы.txt`, если она пуста;
- таблица `Records` хранит результаты игр.

Структуру и данные можно посмотреть в *DB Browser for SQLite*
(https://sqlitebrowser.org/dl/), как в методичке. Ручной импорт CSV не нужен —
программа делает это сама, но при желании можно импортировать и вручную.

Схема таблиц:
```sql
Questions(id, Text, Answer1, Answer2, Answer3, Answer4, RightAnswer, Level)
Records(id, PlayerName, Prize, ReachedLevel, PlayedAt)
```
TOP-10: `SELECT ... FROM Records ORDER BY Prize DESC LIMIT 10`.

## 5. Генерация вопросов через ИИ

Файл `ai_config.properties` (по умолчанию выключено — игра идёт на вопросах из БД):
```
ai.enabled = true
ai.url     = https://api.openai.com/v1/chat/completions
ai.key     = ВАШ_КЛЮЧ
ai.model   = openrouter/free
```
Поддерживается любой сервис с форматом **OpenAI Chat Completions** (OpenAI,
OpenRouter, локальные модели LM Studio/Ollama и т. п.). Модель просят вернуть
вопрос строго в JSON; ответ разбирается собственным мини-парсером `Json.java`
(без внешних библиотек). При любой ошибке (нет ключа, нет сети, плохой ответ)
игра автоматически берёт вопрос из базы данных — то есть приложение остаётся
работоспособным в любом случае.
